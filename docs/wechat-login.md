# 微信登录与用户关联

## 当前接入

原生小程序启动后自动执行微信登录；个人资料中提供失败后的重试入口。

```text
wx.getAccountInfoSync() 读取当前运行的小程序 AppID
  → wx.login() 获取一次性 code
  → cloud.auth.signInWithWechat(code, appid)
  → WorkBuddy 云端校验绑定、与微信换票、签发应用会话
  → 以 session.user.id 切换业务账号
  → 恢复资料与战绩，再启用房间、好友和在线心跳
```

本项目使用内置 SDK 的既有微信登录接口，不另建换票后端。
当前 SDK 契约返回的用户 ID 为 `wx:<openid>`；业务代码使用云端返回的完整 ID，
不接收客户端自报的 openid，也不自行解析 JWT 构造用户身份。

- `utils/wechat-auth.js`：运行环境检查、单飞登录、一次性 code 换票及会话失效处理。
- `utils/user.js`：账号资料切换、分账号战绩、游客本机数据导入与同步。
- `utils/cloud.js` / `utils/room.js`：SDK 初始化与“已验证身份才可调用云端业务”的门禁。
- `pages/index/index.js`：启动登录、分享邀请等待登录、个人资料入口及生命周期处理。

登录成功只确认微信身份，不会自动取得微信头像或昵称；这些仍由用户主动选择、填写。
选择微信头像不代表完成微信登录。

## 正式环境配置

仓库当前仍使用 `project.config.json` 中的 `touristappid` 占位；尚未提供正式 AppID，
因此本次代码接入不代表真实微信账号链路已验收。

1. 注册并取得该产品的微信小程序 AppID，填入 `project.config.json` 的 `appid`。
2. 在 WorkBuddy 云服务对应应用中，按平台支持的流程绑定同一个小程序并开通微信登录。
   云端必须具有该 AppID 对应的凭据，且校验 AppID 与当前应用的绑定关系。
   若当前账号没有该配置入口，需由平台管理方完成。
3. **AppSecret 只保存在平台的服务端凭据配置中**，不放入本仓库、小程序配置、
   `publicConfig` 或客户端环境变量。微信换票得到的 `session_key` 同样不下发给应用。
4. 确认微信后台的 request 合法域名包含现有数据面域名 `https://mp-api.app.workbuddy.host`；
   该地址来自现有云服务公开配置，若平台迁移，使用平台重新下发的配置。
5. 确认 `splendor_players`、`splendor_records`、`splendor_presence`、房间、好友和邀请表
   已存在，且云端权限接受登录后的应用会话。资料、个人战绩和在线心跳的写入所属 uid
   必须由云端认证主体校验；房间、双向好友边与邀请需要按各自参与者权限配置。
   客户端门禁不能替代云端数据权限。本仓库不包含云端建表、凭据管理或权限部署工具。
6. 重新编译到正式 AppID 对应的小程序，使用开发者工具和真机验证。

运行时 AppID 始终读取 `wx.getAccountInfoSync().miniProgram.appId`，不使用硬编码 AppID。
SDK 自行存储、携带和续期应用会话；应用账号缓存本身不作为登录凭证。
同一微信用户在同一小程序 AppID 下具有稳定身份；更换小程序 AppID 不等同于换设备登录，
跨 AppID 的账号合并需要额外的服务端身份映射设计。

## 原有数据的处理

- 首次从游客绑定微信时，若该微信账号尚无云端资料，保留本机昵称、头像和入会时间。
- 若已有云端资料，新设备先恢复这些资料，避免用默认昵称覆盖老账号。
- 游客本机保存的战绩复制到微信账号分区，并分配带目标账号命名空间的新 ID；
  导入的云端补写可重试，不以原记录 ID 改写旧云端账号的数据。
- 账号资料与战绩分别按 uid 备份 / 分区；切换微信账号不会继承另一微信账号的战绩。
- 旧游客的云端好友、邀请、房间不凭客户端自报的旧 uid 自动转移。原记录保留，
  好友需在新微信账号下重新添加；若需批量迁移，须另行提供可证明旧身份归属的服务端流程。
- 身份切换时清除旧房间会话；新的重连会话带 uid，不能被另一个账号自动复用。

## 验证

```sh
# 专项验证：无真实凭据、不请求微信或云服务
node tests/wechat-login.js

# 完整回归，包含预览重建
node tests/run-all.js
```

专项覆盖：游客 AppID、空凭证、并发合流、稳定用户 ID、跨设备资料恢复、账号隔离、
本机战绩导入、存储失败恢复、会话失效、迟到响应和分享邀请等待登录；
另用内置 SDK 与 `wx.request` 替身核对实际换票请求契约。

正式 AppID 配置后需补齐以下真实验收：

- 首次真机启动后显示“微信账号”，重启仍关联相同账号 ID。
- 同一微信用户换设备可恢复资料、战绩和好友。
- 不同微信用户互不串号；分享房间在登录成功后才入席。
- 停用云端微信登录或断网时不误报成功，人机模式仍可使用。
- 用另一用户会话提交不属于自己的个人数据时，云端权限应拒绝。

微信官方流程参考：
[小程序登录](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/login.html)、
[wx.login](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/login/wx.login.html)。
