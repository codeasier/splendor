# 原神本地主题

主题 ID 为 `genshin`，沿用房主选择、房间同步、卡名和贵族命名机制，不改变游戏规则。

## 资源

采用用户确认的 768×768 JPEG 九宫格，图片无额外边框、分隔或姓名。行优先排列：温迪、钟离、雷电影；纳西妲、芙宁娜、玛薇卡；空、荧、派蒙。

原始素材位于用户提供的外部目录，未修改，也没有复制进小程序运行目录。
`preview/prepare-genshin-preview.py` 保存每个角色的独立裁切参数，运行时需要传入原图目录。
`preview/thumbs/themes/genshin-review-atlas.jpg` 是确认后的图集，126596 字节（保持确认的裁切，JPEG quality=65，为同步后的上游资源留出包体余量）。

图集以 Base64 方式嵌入 `pages/index/theme-genshin.wxss`，仅出现一次，供卡牌、贵族和主题入口复用。无原神远程加载请求，无需图片服务器或合法域名配置；主题图片可离线显示，但联网房间等功能仍受网络条件影响。原有游戏卡牌外框和文字 UI 保留，不属于图片像素。
